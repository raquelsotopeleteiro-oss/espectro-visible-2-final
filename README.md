# El espectro invisible · Revisión V2

## Imágenes
La carpeta SharePoint no pudo descargarse desde el entorno de generación. Coloca las imágenes en `public/images` usando los nombres indicados en `public/images/README.txt`. Mientras falten, la web muestra marcadores descriptivos.

## Vercel
Framework: Vite. Build: `npm run build`. Output: `dist`.
